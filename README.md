# peti-si886

Repositorio de papeles de trabajo del curso **SI-886 Planeamiento Estratégico de TI**
(Universidad Privada de Tacna). Contiene la evidencia acumulada del PETI construido
a lo largo del semestre.

## Semana 02 — Vigilancia estratégica con fuentes oficiales

- `01_marco/VS01_fuentes.csv` — matriz de fuentes oficiales pertinentes al sector.
- `01_marco/VS02_05_generacion_datos.py` — script de extracción/consolidación de las
  series del BCRP y del Banco Mundial, y construcción de la matriz de vigilancia.
- `01_marco/VS04_graficos.py` — script de visualización (gráfico de contexto).
- `01_marco/VS05_matriz_vigilancia.csv` — matriz de vigilancia estratégica.
- `01_marco/1.1_contexto_tendencias.md` — Sección 1.1 del PETI: Contexto y tendencias.
- `evidencias/` — series descargadas (BCRP, Banco Mundial) con URL de origen y fecha
  de descarga, y `HASHES.txt` con el SHA-256 de cada artefacto.
- `graficos/VS_contexto.png` — gráfico de contexto generado a partir de las series.
- `SI886-LAB-02_vargas.docx` — informe de laboratorio en formato APA 7.
